# 砚衡AI云数据升学规划系统 前端(zytb-vue)

Vue 3 + TypeScript + Vite + Element Plus + Pinia,与魄力学习前端同构(request 封装/加密信封开关/路由守卫/角色布局)。

```bash
npm install
npm run dev      # http://localhost:3000,代理 /api → http://localhost:8800
npm run build    # vue-tsc 类型检查 + 产物
```

对接后端:zytb-java(网关 8800)。登录页/路由守卫/角色跳转已可用,业务页面为占位待开发。
